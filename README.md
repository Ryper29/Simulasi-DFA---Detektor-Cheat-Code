# Simulasi DFA - Detektor Cheat Code

Aplikasi web simulasi **Deterministic Finite Automata (DFA)** untuk validasi multi-cheat code game.

## Deskripsi

Aplikasi ini mensimulasikan cara kerja Deterministic Finite Automata dalam mendeteksi dan memvalidasi berbagai cheat code dalam sebuah game. Pengguna dapat memasukkan input secara manual maupun melalui controller virtual yang disediakan, lalu sistem akan memproses input tersebut menggunakan mesin DFA dan memberikan feedback secara real-time.

## Teknologi

- **HTML** — Struktur halaman web
- **Tailwind CSS** — Styling dan desain antarmuka
- **JavaScript** — Logika DFA dan interaktivitas

## Fitur

- 🎮 **Controller Virtual** — Input cheat code melalui tombol controller yang tampil di layar
- 🔵 **State Aktif** — Visualisasi state DFA yang sedang aktif secara real-time
- 📜 **Riwayat Input** — Rekam jejak seluruh input yang telah dimasukkan
- 🏆 **Achievement** — Notifikasi dan pencapaian saat cheat code berhasil dideteksi
- 📊 **Tabel Transisi DFA** — Tampilan lengkap tabel transisi state DFA
- 🔄 **Reset Otomatis** — Reset state DFA secara otomatis setelah deteksi selesai

## Cara Penggunaan

1. Buka file `index.html` di browser
2. Gunakan **controller virtual** atau **keyboard** untuk memasukkan input
3. Amati perpindahan **state aktif** pada diagram DFA
4. Jika urutan input sesuai cheat code, **achievement** akan muncul secara otomatis
5. Gunakan tombol **Reset** untuk memulai ulang
